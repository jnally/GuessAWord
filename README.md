# Guess A Word

## Purpose
This is a C# Windows Forms application that converts a console-based word-guessing game from another homework assignment into an interactive graphical user interface. The player attempts to guess a hidden word one letter at a time. Real-time feedback is given on puzzle progress and whether input is valid. This project was developed to demonstrate event-driven programming, input validation, and graphical user interfaces.

## How to Run
1. Clone this repository or download the source code to your local machine.
2. Open the GuessAWord.sln solution file using Visual Studio.
3. Ensure the project is set to run as a Windows Forms Application.
4. Click the Start button in the Visual Studio toolbar to build and launch the game.
